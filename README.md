# sewu.org

Personal site for Arthur Sewu — Full Stack Marketer.

Static site (plain HTML/CSS/JS), served by GitHub Pages at **https://sewu.org**.

## Editing

Edit the files, commit, push to `main`. GitHub Pages rebuilds in ~30–60 seconds.

```
index.html    page markup
style.css     all styling
script.js     interactions
assets/       favicon, testimonial images, hero video
CNAME         custom domain binding — do not delete
```

## Domain

- Registrar: Namecheap (Namecheap BasicDNS)
- Apex `sewu.org` → four GitHub Pages A records (185.199.108–111.153)
- `www.sewu.org` → CNAME to `arthursewu.github.io.`
- `_github-pages-challenge-arthursewu` TXT record verifies the domain to this account — **leave it in place**
